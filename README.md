## Destaque: projetos de saúde

Três projetos do portfólio tratam de operações de saúde:

- [Dashboard-Rede-Credenciada](Dashboard-Rede-Credenciada) — Análise operacional, financeira, qualidade dos dados e monitoramento da rede credenciada de uma operadora de saúde, utilizando Power BI, Python, DAX, Power Query e modelagem dimensional.
- [Dashboard-Cirurgias-Oftalmologicas](Dashboard-Cirurgias-Oftalmologicas) — Análise completa da jornada de cirurgias oftalmológicas, contemplando solicitações, autorizações, agendamentos, reagendamentos, performance cirúrgica, indicadores financeiros e análise por convênio.
- [Dashboard-Clinica](Dashboard-Clinica) — Análise de performance médica, convênios e indicadores operacionais.
